# Fretmap v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a desktop-first web app that lights up every note of any chord across a guitar neck in any six-string tuning, with capo, Names/Numbers labels, saved tunings, and a single-file build.

**Architecture:** Plain ES modules with no dependencies. Pure logic (`src/theory/`, `src/fretboard/`, `src/tunings.js`, `src/state.js`) is built test-first and never touches the DOM. `src/ui/` renders SVG and HTML from it. `src/main.js` is the only module that touches `location`, `history` and `localStorage`. `build.mjs` inlines everything into `dist/fretmap.html`.

**Tech Stack:** Vanilla JavaScript (ES modules), SVG, CSS custom properties, and Node 24 for tests, the dev server and the build (standard library only).

**Spec:** `docs/superpowers/specs/2026-09-29-fretmap-chord-map-design.md`

**Repo:** `fretmap/` (already initialised on `main` with the spec and a `.gitignore` containing `dist/`, `.superpowers/` and `desktop.ini`). Run every command from the repo root. End every commit message with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Module rule (the build relies on it):** only `export function` / `export const` / `export let` / `export class` declarations, and only `import { a, b } from './relative.js';` on a single line with single quotes. No default exports, no `export { … }` lists, no re-exports, no dynamic imports.

```js
const failures = [];
let passed = 0;

export function check(name, fn) {
  try {
    fn();
    passed++;
  } catch (err) {
    failures.push(`${name}: ${err.message}`);
  }
}

export function assert(cond, msg) {
  if (!cond) throw new Error(msg || 'assertion failed');
}

export function assertEqual(actual, expected, msg) {
  const a = JSON.stringify(actual);
  const e = JSON.stringify(expected);
  if (a !== e) throw new Error(`${msg || 'not equal'}: expected ${e}, got ${a}`);
}

export function report() {
  for (const failure of failures) console.error(`FAIL ${failure}`);
  console.log(`${passed} passed, ${failures.length} failed`);
  process.exit(failures.length ? 1 : 0);
}
```

```js
// Notes: spelled notes { letter, acc }, pitch classes, and MIDI <-> "D2" names.
// C4 = MIDI 60. The octave follows the letter, so B#3 is MIDI 60 and Cb4 is MIDI 59.

export const LETTERS = ['C', 'D', 'E', 'F', 'G', 'A', 'B'];
const NATURAL_PC = { C: 0, D: 2, E: 4, F: 5, G: 7, A: 9, B: 11 };
export const SHARP_NAMES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'];
export const FLAT_NAMES = ['C', 'Db', 'D', 'Eb', 'E', 'F', 'Gb', 'G', 'Ab', 'A', 'Bb', 'B'];
// How open strings are named when the tuning matches no preset.
const STRING_NAMES = ['C', 'C#', 'D', 'Eb', 'E', 'F', 'F#', 'G', 'G#', 'A', 'Bb', 'B'];

export function mod12(n) {
  return ((n % 12) + 12) % 12;
}

export function pitchClass(note) {
  return mod12(NATURAL_PC[note.letter] + note.acc);
}

export function noteName(note) {
  return note.letter + (note.acc > 0 ? '#'.repeat(note.acc) : 'b'.repeat(-note.acc));
}

// "C", "c#", "Bb" -> { letter, acc }. Single accidentals only; anything else is null.
export function parseNote(text) {
  const m = /^([A-Ga-g])([#b]?)$/.exec(text);
  if (!m) return null;
  return { letter: m[1].toUpperCase(), acc: m[2] === '#' ? 1 : m[2] === 'b' ? -1 : 0 };
}

// The note `semis` above `root`, spelled on the letter `degree - 1` steps above the root's
// letter. May come out with a double accidental (G# + #5 = D##); that is correct spelling.
export function spellInterval(root, degree, semis) {
  const letter = LETTERS[(LETTERS.indexOf(root.letter) + degree - 1) % 7];
  let acc = mod12(pitchClass(root) + semis - NATURAL_PC[letter]);
  if (acc > 6) acc -= 12;
  return { letter, acc };
}

export function pcName(pc, flats) {
  return (flats ? FLAT_NAMES : SHARP_NAMES)[mod12(pc)];
}

export function midiToName(midi) {
  return STRING_NAMES[mod12(midi)] + (Math.floor(midi / 12) - 1);
}

// "E2", "Eb2", "F#3" -> MIDI number, or null.
export function nameToMidi(text) {
  const m = /^([A-G])([#b]?)(-?\d)$/.exec(text);
  if (!m) return null;
  const acc = m[2] === '#' ? 1 : m[2] === 'b' ? -1 : 0;
  return (Number(m[3]) + 1) * 12 + NATURAL_PC[m[1]] + acc;
}
```

```js
// Chord symbols -> chord objects. Never throws: anything unrecognised is null.
import { parseNote, noteName, pitchClass, spellInterval, mod12 } from './notes.js';
import { findType } from './chords.js';

// Labels for a slash bass that is not a chord tone, by semitones above the root.
const BASS_LABELS = ['1', 'b2', '2', 'b3', '3', '4', 'b5', '5', 'b6', '6', 'b7', '7'];
// Root names for "Shape from capo".
const SHAPE_NAMES = ['C', 'Db', 'D', 'Eb', 'E', 'F', 'F#', 'G', 'Ab', 'A', 'Bb', 'B'];

export function parseChord(text) {
  if (typeof text !== 'string') return null;
  const m = /^([A-Ga-g][#b]?)\s*(.*)$/.exec(text.trim());
  if (!m) return null;
  const root = parseNote(m[1]);
  const rest = m[2];

  // The whole remainder as a suffix first, so "6/9" is not read as a slash chord.
  let type = findType(rest);
  let bass = null;
  if (!type) {
    const slash = rest.lastIndexOf('/');
    if (slash < 0) return null;
    type = findType(rest.slice(0, slash).trim());
    bass = parseNote(rest.slice(slash + 1).trim());
    if (!type || !bass) return null;
  }
  return buildChord(root, type, bass);
}

export function buildChord(root, type, bass) {
  const tones = type.intervals.map((iv) => ({
    note: spellInterval(root, iv.degree, iv.semis),
    semis: iv.semis,
    label: iv.label,
    role: iv.role,
    isBass: false,
  }));
  if (bass) {
    const match = tones.find((t) => pitchClass(t.note) === pitchClass(bass));
    if (match) {
      match.isBass = true;
    } else {
      const semis = mod12(pitchClass(bass) - pitchClass(root));
      tones.push({ note: bass, semis, label: BASS_LABELS[semis], role: 'bass', isBass: true });
    }
  }
  const symbol = noteName(root) + type.suffix + (bass ? `/${noteName(bass)}` : '');
  return { symbol, root, type, bass, tones };
}

// The chord shape you finger behind a capo: E with capo 2 is a "D" shape.
export function capoShape(chord, capo) {
  const name = (note) => SHAPE_NAMES[mod12(pitchClass(note) - capo)];
  return name(chord.root) + chord.type.suffix + (chord.bass ? `/${name(chord.bass)}` : '');
}
```

```js
// The searchable chord list: 17 root spellings x every chord type. Slash chords are not
// listed; they reach the results only through the parser.
import { CHORD_TYPES } from './chords.js';
import { parseNote, noteName } from './notes.js';
import { parseChord, buildChord } from './parse.js';

export const ROOT_SPELLINGS = ['C', 'C#', 'Db', 'D', 'D#', 'Eb', 'E', 'F', 'F#', 'Gb', 'G', 'G#', 'Ab', 'A', 'A#', 'Bb', 'B'];

export const CATALOG = ROOT_SPELLINGS.flatMap((r) =>
  CHORD_TYPES.map((type) => buildChord(parseNote(r), type, null)));

// Results for the search box. Exact parse first (covers slash chords), then catalog entries
// with the same root whose suffix or an alias starts with what was typed after the root.
export function searchChords(input, currentRoot = 'C', limit = 50) {
  const text = input.trim();
  if (!text) {
    const root = parseNote(currentRoot) || parseNote('C');
    return CHORD_TYPES.map((type) => buildChord(root, type, null)).slice(0, limit);
  }

  const results = [];
  const exact = parseChord(text);
  if (exact) results.push(exact);

  const m = /^([A-Ga-g][#b]?)\s*(.*)$/.exec(text);
  if (!m) return results;
  const rootName = noteName(parseNote(m[1]));
  const rest = m[2];
  for (const chord of CATALOG) {
    if (results.length >= limit) break;
    if (noteName(chord.root) !== rootName) continue;
    if (exact && chord.symbol === exact.symbol) continue;
    const names = [chord.type.suffix, ...chord.type.aliases];
    if (names.some((n) => n.startsWith(rest))) results.push(chord);
  }
  return results;
}
```

```js
// Key-relative degree labels for the Numbers view, and which key a chord implies.
import { mod12, pitchClass, noteName } from './notes.js';

const LABELS = ['1', 'b2', '2', 'b3', '3', '4', '#4', '5', 'b6', '6', 'b7', '7'];
const IN_KEY = {
  major: [0, 2, 4, 5, 7, 9, 11],
  minor: [0, 2, 3, 5, 7, 8, 10],
};
export const KEY_NAMES = {
  major: ['C', 'Db', 'D', 'Eb', 'E', 'F', 'F#', 'G', 'Ab', 'A', 'Bb', 'B'],
  minor: ['Cm', 'C#m', 'Dm', 'Ebm', 'Em', 'Fm', 'F#m', 'Gm', 'G#m', 'Am', 'Bbm', 'Bm'],
};
const FLAT_KEYS = {
  major: ['F', 'Bb', 'Eb', 'Ab', 'Db', 'Gb', 'Cb'],
  minor: ['D', 'G', 'C', 'F', 'Bb', 'Eb', 'Ab'],
};

// key = { root: 0..11, mode: 'major' | 'minor' }
export function degreeLabel(pc, key) {
  const i = mod12(pc - key.root);
  return { label: LABELS[i], inKey: IN_KEY[key.mode].includes(i) };
}

// Minor if the chord has a b3 and no 3 (m, dim, m7b5 …); otherwise major.
export function keyForChord(chord) {
  const semis = chord.tones.filter((t) => t.role !== 'bass').map((t) => t.semis);
  const minor = semis.includes(3) && !semis.includes(4);
  return { root: pitchClass(chord.root), mode: minor ? 'minor' : 'major' };
}

// Should the faint note names use flats? Yes for a flat root, or a root whose key
// (major, or minor per keyForChord) has flats in its key signature.
export function prefersFlats(chord) {
  if (!chord) return false;
  if (chord.root.acc < 0) return true;
  return FLAT_KEYS[keyForChord(chord).mode].includes(noteName(chord.root));
}
```

```js
// Tuning + capo + fret count + chord -> a grid of cells, one row per string.
// Row 0 is string 6 (tuning[0]). Pure: the renderer and the future voicing finder read this.
import { mod12, pitchClass } from '../theory/notes.js';

export function mapFretboard({ tuning, capo, frets, chord }) {
  return tuning.map((open) => {
    const row = [];
    for (let fret = 0; fret <= frets; fret++) {
      const midi = open + fret;
      const pc = mod12(midi);
      const tone = chord ? chord.tones.find((t) => pitchClass(t.note) === pc) || null : null;
      row.push({ fret, midi, pc, playable: fret >= capo, tone });
    }
    return row;
  });
}
```

```js
// Tuning presets, saved favourites, and naming a tuning. A tuning is 6 MIDI numbers,
// string 6 first.
import { nameToMidi, midiToName } from './theory/notes.js';

export const MIN_MIDI = 23; // B0
export const MAX_MIDI = 72; // C6

export const PRESETS = [
  ['Standard', 'E2 A2 D3 G3 B3 E4'],
  ['Drop D', 'D2 A2 D3 G3 B3 E4'],
  ['Double Drop D', 'D2 A2 D3 G3 B3 D4'],
  ['DADGAD', 'D2 A2 D3 G3 A3 D4'],
  ['Open D', 'D2 A2 D3 F#3 A3 D4'],
  ['Open Dm', 'D2 A2 D3 F3 A3 D4'],
  ['Open G', 'D2 G2 D3 G3 B3 D4'],
  ['Open C', 'C2 G2 C3 G3 C4 E4'],
  ['Open E', 'E2 B2 E3 G#3 B3 E4'],
  ['Open A', 'E2 A2 E3 A3 C#4 E4'],
  ['Eb Standard', 'Eb2 Ab2 Db3 Gb3 Bb3 Eb4'],
  ['D Standard', 'D2 G2 C3 F3 A3 D4'],
].map(([name, notes]) => ({ name, notes: notes.split(' '), tuning: notes.split(' ').map(nameToMidi) }));

export const STANDARD = PRESETS[0].tuning;

const same = (a, b) => a.length === b.length && a.every((v, i) => v === b[i]);

export function isValidTuning(t) {
  return Array.isArray(t) && t.length === 6 &&
    t.every((m) => Number.isInteger(m) && m >= MIN_MIDI && m <= MAX_MIDI);
}

export function stepString(tuning, index, delta) {
  const next = tuning.slice();
  next[index] = Math.min(MAX_MIDI, Math.max(MIN_MIDI, next[index] + delta));
  return next;
}

export function tuningName(tuning, favourites = []) {
  const fav = favourites.find((f) => same(f.tuning, tuning));
  if (fav) return fav.name;
  const preset = PRESETS.find((p) => same(p.tuning, tuning));
  return preset ? preset.name : 'Custom';
}

// Open-string labels: a preset's own spellings when it matches one, otherwise generic.
export function stringNames(tuning) {
  const preset = PRESETS.find((p) => same(p.tuning, tuning));
  return preset ? preset.notes.slice() : tuning.map(midiToName);
}

const STORE_KEY = 'fretmap.tunings.v1';

// `storage` is localStorage or anything with getItem/setItem; null keeps favourites in
// memory only. Storage errors and corrupted data never break the app.
export function createFavouriteStore(storage) {
  let items = load();

  function load() {
    if (!storage) return [];
    try {
      const raw = storage.getItem(STORE_KEY);
      if (!raw) return [];
      const data = JSON.parse(raw);
      if (!Array.isArray(data)) throw new Error('not an array');
      return data.filter((f) => f && typeof f.name === 'string' && f.name && isValidTuning(f.tuning));
    } catch (err) {
      console.warn('fretmap: ignoring saved tunings:', err.message);
      return [];
    }
  }

  function persist() {
    if (!storage) return;
    try {
      storage.setItem(STORE_KEY, JSON.stringify(items));
    } catch (err) {
      console.warn('fretmap: could not save tunings:', err.message);
    }
  }

  return {
    list: () => items.map((f) => ({ name: f.name, tuning: f.tuning.slice() })),
    save(name, tuning) {
      items = items.filter((f) => f.name !== name).concat([{ name, tuning: tuning.slice() }]);
      persist();
    },
    remove(name) {
      items = items.filter((f) => f.name !== name);
      persist();
    },
  };
}
```

```js
    frets: 15,
    chord: null,
    labels: 'names',
    key: { root: 0, mode: 'major' },
    keyPinned: false,
  };
}

// Keep at least 3 frets above the capo.
export function fitFrets(capo, frets) {
  if (capo <= frets - 3) return frets;
  return FRET_OPTIONS.find((f) => capo <= f - 3);
}

// Choosing a chord moves the key to it unless the key is pinned.
export function selectChord(state, chord) {
  const next = { ...state, chord };
  if (chord && !state.keyPinned) next.key = keyForChord(chord);
  return next;
}

export function stateToHash(s) {
  const p = new URLSearchParams();
  p.set('t', s.tuning.join('.'));
  p.set('capo', String(s.capo));
  p.set('f', String(s.frets));
  if (s.chord) p.set('c', s.chord.symbol);
  p.set('l', s.labels);
  p.set('k', `${s.key.root}.${s.key.mode === 'minor' ? 'min' : 'maj'}`);
  if (s.keyPinned) p.set('kp', '1');
  return `#${p.toString()}`;
}

// Each part is checked on its own; a bad part falls back to its default.
export function hashToState(hash) {
  const p = new URLSearchParams(String(hash || '').replace(/^#/, ''));
  const s = defaultState();

  const t = (p.get('t') || '').split('.').map(Number);
  if (isValidTuning(t)) s.tuning = t;

  const capo = p.get('capo');
  if (/^\d+$/.test(capo || '') && Number(capo) <= MAX_CAPO) s.capo = Number(capo);

  const f = Number(p.get('f'));
  if (FRET_OPTIONS.includes(f)) s.frets = f;
  s.frets = fitFrets(s.capo, s.frets);

  if (p.has('c')) s.chord = parseChord(p.get('c'));

  if (p.get('l') === 'numbers') s.labels = 'numbers';

  const k = /^(\d+)\.(maj|min)$/.exec(p.get('k') || '');
  if (k && Number(k[1]) < 12) s.key = { root: Number(k[1]), mode: k[2] === 'min' ? 'minor' : 'major' };
  else if (s.chord) s.key = keyForChord(s.chord);

  s.keyPinned = p.get('kp') === '1';
  return s;
}
```

```js
// Inlines src/ into one self-contained HTML file: dist/fretmap.html. It works when
// double-clicked (ES modules don't load from file://) and on any static host.
//
//   node build.mjs
//
// Each module becomes a function registered under its path in `__m`. Named imports become
// destructuring from that registry; `export` keywords are dropped and the names returned.
// Only the module style the spec allows is supported: anything else is a build error.
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { dirname, join, relative, resolve } from 'node:path';
import { fileURLToPath, pathToFileURL } from 'node:url';

const ROOT = dirname(fileURLToPath(import.meta.url));
const IMPORT_RE = /^import\s*\{([^}]*)\}\s*from\s*'(\.[^']+)';[ \t]*$/gm;
const EXPORT_RE = /^export\s+(?:async\s+)?(?:function\*?|const|let|class)\s+([A-Za-z_$][\w$]*)/gm;
const SCRIPT_TAG = '<script type="module" src="src/main.js"></script>';

const idOf = (file) => relative(ROOT, file).split('\\').join('/');

// Returns JS that defines `__m` and fills it with `entry` and everything it imports.
export function bundle(entry) {
  const order = [];
  const seen = new Set();

  function visit(file) {
    if (seen.has(file)) return;
    seen.add(file);
    const src = readFileSync(file, 'utf8');
    for (const [, , spec] of src.matchAll(IMPORT_RE)) visit(resolve(dirname(file), spec));
    order.push(file);
  }
  visit(resolve(ROOT, entry));

  const parts = order.map((file) => {
    const src = readFileSync(file, 'utf8');
    const exports = [...src.matchAll(EXPORT_RE)].map((m) => m[1]);
    const body = src
      .replace(IMPORT_RE, (_, names, spec) =>
        `const {${names.replace(/\s+as\s+/g, ': ')}} = __m[${JSON.stringify(idOf(resolve(dirname(file), spec)))}];`)
      .replace(/^export\s+/gm, '');
    const leftover = body.match(/^\s*(import|export)\b.*$/m);
    if (leftover) throw new Error(`${idOf(file)}: unsupported module syntax: ${leftover[0].trim()}`);
    return `__m[${JSON.stringify(idOf(file))}] = (() => {\n${body}\nreturn { ${exports.join(', ')} };\n})();`;
  });
  return `const __m = {};\n${parts.join('\n')}\n`;
}

export function buildHtml() {
  const html = readFileSync(join(ROOT, 'index.html'), 'utf8');
  if (!html.includes(SCRIPT_TAG)) throw new Error(`index.html must contain ${SCRIPT_TAG}`);
  const js = `(() => {\n${bundle('src/main.js')}})();`;
  return html.replace(SCRIPT_TAG, () => `<script>\n${js}\n</script>`);
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  const out = join(ROOT, 'dist', 'fretmap.html');
  mkdirSync(dirname(out), { recursive: true });
  const html = buildHtml();
  writeFileSync(out, html);
  console.log(`wrote dist/fretmap.html (${html.length} bytes)`);
}
```

- `replace(SCRIPT_TAG, () => …)` uses a function on purpose, so `$` sequences in the bundled code aren't treated as replacement patterns.

```js
import { searchChords } from '../theory/catalog.js';

export function mountSearch(el, actions) {
  el.innerHTML = `
    <div class="search">
      <input id="chord-input" type="text" role="combobox" aria-expanded="false" aria-controls="chord-list"

  const list = el.querySelector('ul');
  let results = [];
  let active = 0;
  let current = null;

  function refresh() {
    results = searchChords(input.value, current ? noteName(current.root) : 'C');
    active = 0;
    list.replaceChildren();
    if (!results.length) {
      const li = document.createElement('li');
      li.className = 'empty';
      li.textContent = `No chord matches "${input.value.trim()}"`;
      list.append(li);
    }
    results.forEach((chord, i) => {
      const li = document.createElement('li');
      li.id = `chord-opt-${i}`;
      li.setAttribute('role', 'option');
      const sym = document.createElement('span');
      sym.textContent = chord.symbol;
      const name = document.createElement('span');
      name.className = 'name';
      name.textContent = chord.type.name + (chord.bass ? ` over ${noteName(chord.bass)}` : '');
      li.append(sym, name);
      // mousedown, not click, so the input's blur doesn't close the list first.
      li.addEventListener('mousedown', (e) => {
        e.preventDefault();
        pick(chord);
      });
      list.append(li);
    });
    open(true);
    highlight();
  }

  function highlight() {
    [...list.children].forEach((li, i) => li.setAttribute('aria-selected', String(i === active)));
    const li = list.children[active];
    if (li && li.id) {
      input.setAttribute('aria-activedescendant', li.id);
      li.scrollIntoView({ block: 'nearest' });
    }
  }

  function open(on) {
    list.hidden = !on;
    input.setAttribute('aria-expanded', String(on));
    if (!on) input.removeAttribute('aria-activedescendant');
  }

  function pick(chord) {
    open(false);
    input.value = chord.symbol;
    actions.setChord(chord);
  }

  input.addEventListener('focus', () => {
    input.select();
    refresh();
  });
  input.addEventListener('input', refresh);
  input.addEventListener('blur', () => {
    open(false);
    input.value = current ? current.symbol : '';
  });
  input.addEventListener('keydown', (e) => {
    if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
      e.preventDefault();
      if (list.hidden) return refresh();
      if (!results.length) return;
      active = (active + (e.key === 'ArrowDown' ? 1 : -1) + results.length) % results.length;
      highlight();
    } else if (e.key === 'Enter') {
      e.preventDefault();
      if (results[active]) pick(results[active]);
    } else if (e.key === 'Escape') {
      open(false);
      input.value = current ? current.symbol : '';
    }
  });

  return {
    update(state) {
      current = state.chord;
      if (document.activeElement !== input) input.value = current ? current.symbol : '';
    },
  };
}
```

```js
    const neckH = ROW * 6;
    const cx = (fret) => (fret === 0 ? OPEN_W / 2 : OPEN_W + (fret - 0.5) * fretW);
    const cy = (row) => ROW * (row + 0.5);

    const root = svg('svg', { width, height, viewBox: `0 0 ${width} ${height}`, role: 'img', 'aria-label': 'Fretboard' });

    for (const f of INLAYS) if (f <= frets) root.append(svg('circle', { cx: cx(f), cy: neckH / 2, r: 7, fill: 'var(--inlay)' }));
    for (const f of DOUBLE_INLAYS) {
      if (f > frets) continue;
      root.append(svg('circle', { cx: cx(f), cy: ROW * 1.5, r: 7, fill: 'var(--inlay)' }));
      root.append(svg('circle', { cx: cx(f), cy: ROW * 4.5, r: 7, fill: 'var(--inlay)' }));
    }
    for (let f = 1; f <= frets; f++) {
      const x = OPEN_W + f * fretW;
      root.append(svg('line', { x1: x, x2: x, y1: ROW / 2, y2: neckH - ROW / 2, stroke: 'var(--fret)', 'stroke-width': 2 }));
    }
    root.append(svg('line', { x1: OPEN_W, x2: OPEN_W, y1: ROW / 2 - 4, y2: neckH - ROW / 2 + 4, stroke: 'var(--nut)', 'stroke-width': 6 }));
    for (let r = 0; r < 6; r++) {
      root.append(svg('line', { x1: 0, x2: width, y1: cy(r), y2: cy(r), stroke: 'var(--string)', 'stroke-width': 1 + r * 0.3 }));
    }
    if (capo > 0) {
      const x = OPEN_W + capo * fretW - 6;
      root.append(svg('rect', { x: x - 4, y: ROW / 2 - 8, width: 8, height: neckH - ROW + 16, rx: 3, fill: 'var(--capo)' }));
    }

    for (let r = 0; r < 6; r++) {
      const row = cells[5 - r]; // display row 0 is string 1
      for (const cell of row) {
        const g = svg('g', { opacity: cell.playable ? 1 : 0.25 });
        const x = cx(cell.fret);
        const y = cy(r);
        const degree = labels === 'numbers' ? degreeLabel(cell.pc, key) : null;
        if (cell.tone) {
          const t = cell.tone;
          if (t.isBass) g.append(svg('circle', { cx: x, cy: y, r: DOT_R + 3, fill: 'none', stroke: 'var(--text)', 'stroke-width': 2 }));
          g.append(svg('circle', { cx: x, cy: y, r: DOT_R, fill: `var(--${t.role})` }));
          const text = degree ? degree.label : t.label === '1' ? 'R' : t.label;
          const ink = t.role === 'extension' ? '#1c1917' : '#ffffff';
          g.append(svg('text', { x, y: y + 4, 'text-anchor': 'middle', 'font-size': 11, 'font-weight': 700, fill: ink }, text));
        } else {
          const text = degree ? degree.label : pcName(cell.pc, flats);
          const faded = degree && !degree.inKey;
          g.append(svg('rect', { x: x - 11, y: y - 7, width: 22, height: 14, fill: 'var(--bg)' }));
          g.append(svg('text', { x, y: y + 4, 'text-anchor': 'middle', 'font-size': 10, fill: 'var(--faint)', opacity: faded ? 0.5 : 1 }, text));
        }
        root.append(g);
      }
    }

    for (let f = 1; f <= frets; f++) {
      const label = f === capo ? 'capo' : [...INLAYS, ...DOUBLE_INLAYS].includes(f) ? String(f) : '';
      if (label) root.append(svg('text', { x: cx(f), y: neckH + 16, 'text-anchor': 'middle', 'font-size': 11, fill: 'var(--muted)' }, label));
    }

    el.replaceChildren(tuners, root);
  }

  return { update: render };
}
```

Geometry: the tuner rows and the SVG strings share `ROW = 40`, so each ▲▼ lines up with its string. The capo bar is drawn just behind fret wire `capo`, and cells with `fret < capo` render at 25% opacity. Frets widen to fill the window (40–80 px each) and the board scrolls sideways when they can't fit.

```js
// Info line under the neck: chord name, notes, formula, bass, and the capo shape.
import { noteName } from '../theory/notes.js';
import { capoShape } from '../theory/parse.js';

export function mountInfo(el) {
  function item(label, value, cls) {
    const span = document.createElement('span');
    if (cls) span.className = cls;
    if (label) span.append(`${label}: `);
    const b = document.createElement('b');
    b.textContent = value;
    span.append(b);
    return span;
  }

  return {
    update(state) {
      const { chord, capo } = state;
      if (!chord) {
        el.replaceChildren('Pick a chord to light up its notes.');
        return;
      }
      const tones = chord.tones.filter((t) => t.role !== 'bass');
      const title = item('', chord.symbol, 'title');
      title.append(` ${chord.type.name}`);
      const parts = [
        title,
        item('Notes', tones.map((t) => noteName(t.note)).join(' ')),
        item('Formula', tones.map((t) => t.label).join(' ')),
      ];
      if (chord.bass) parts.push(item('Bass', noteName(chord.bass)));
      if (capo > 0) {
        const shape = item('Shape from capo', capoShape(chord, capo));
        shape.append(` (plays as ${chord.symbol})`);
        parts.push(shape);
      }
      el.replaceChildren(...parts);
    },
  };
}
```

```js
// Wires state to the UI. The only module that touches location, history and storage.
import { hashToState, stateToHash, selectChord, fitFrets } from './state.js';
import { createFavouriteStore, stepString } from './tunings.js';
import { mountToolbar } from './ui/toolbar.js';
import { mountSearch } from './ui/search.js';
import { mountFretboard } from './ui/fretboard.js';
import { mountInfo } from './ui/info.js';

function getStorage() {
  try {
    return window.localStorage;
  } catch {
    return null;
  }
}

const favourites = createFavouriteStore(getStorage());
let state = hashToState(location.hash);

function commit(next) {
  state = next;
  history.replaceState(null, '', stateToHash(state));
  render();
}

const actions = {
  setTuning: (tuning) => commit({ ...state, tuning }),
  stepString: (index, delta) => commit({ ...state, tuning: stepString(state.tuning, index, delta) }),
  setCapo: (capo) => commit({ ...state, capo, frets: fitFrets(capo, state.frets) }),
  setFrets: (frets) => commit({ ...state, frets: fitFrets(state.capo, frets) }),
  setChord: (chord) => commit(selectChord(state, chord)),
  setLabels: (labels) => commit({ ...state, labels }),
  setKey: (key) => commit({ ...state, key }),
  togglePin: () => commit({ ...state, keyPinned: !state.keyPinned }),
  saveFavourite(name) {
    favourites.save(name, state.tuning);
    render();
  },
  deleteFavourite(name) {
    favourites.remove(name);
    render();
  },
};

const toolbar = mountToolbar(document.getElementById('toolbar'), actions);
const search = mountSearch(toolbar.searchSlot, actions);
const board = mountFretboard(document.getElementById('board'), actions);
const info = mountInfo(document.getElementById('info'));

function render() {
  toolbar.update(state, favourites.list());
  search.update(state);
  board.update(state);
  info.update(state);
}

history.replaceState(null, '', stateToHash(state));
render();
```

```js
// Development server: ES modules don't load from file://, so serve the repo over HTTP.
// Node standard library only.
//
//   node serve.mjs          then open http://localhost:8124
import { createServer } from 'node:http';
import { readFileSync } from 'node:fs';

const PORT = 8124;
const root = new URL('./', import.meta.url);

const TYPES = { html: 'text/html; charset=utf-8', js: 'text/javascript; charset=utf-8', mjs: 'text/javascript; charset=utf-8', md: 'text/plain; charset=utf-8' };

createServer((req, res) => {
  const path = decodeURIComponent((req.url === '/' ? '/index.html' : req.url).split('?')[0]);
  // Keep the server to its own directory: no traversal out of the project.
  if (path.includes('..')) {
    res.writeHead(403).end('forbidden');
    return;
  }
  try {
    const body = readFileSync(new URL(`.${path}`, root));
    const ext = path.split('.').pop();
    res.writeHead(200, { 'content-type': TYPES[ext] || 'application/octet-stream', 'cache-control': 'no-store' });
    res.end(body);
  } catch {
    res.writeHead(404).end('not found');
  }
}).listen(PORT, '127.0.0.1', () => {
  console.log(`Fretmap dev server: http://localhost:${PORT}  (Ctrl+C to stop)`);
});
```

````markdown
# Fretmap

Pick a tuning, add a capo, choose a chord: every note of that chord lights up across the
whole neck, coloured by what it does in the chord. Built for open and alternate tunings.
Desktop first; works on a phone with sideways scrolling.

No dependencies. Plain ES modules in `src/`, combined into one HTML file for use.

## Use

```bash
node build.mjs
```

Then double-click `dist/fretmap.html`, or drag the `dist/` folder onto
[Netlify Drop](https://app.netlify.com/drop) to use it from a phone.

## Develop

```bash
node serve.mjs
```

Open http://localhost:8124. ES modules don't load from `file://`, so the dev copy needs the
server; the built file doesn't.

## Test

```bash
node tests/run.mjs
```

Node standard library only. Covers everything in `src/theory/`, `src/fretboard/`,
`src/tunings.js`, `src/state.js`, and the build's module bundling. The UI is checked by
hand.

## Colours

Okabe–Ito palette, chosen to stay distinct with red/green colour blindness. Every dot also
carries its interval label, so colour is never the only cue.

| Role | Intervals | Colour |
|---|---|---|
| root | 1 | vermillion |
| third | b3, 3, sus2, sus4 | blue |
| fifth | b5, 5, #5 | green |
| seventh | 6, bb7, b7, 7 | purple |
| extension | 9s, 11s, 13s | amber |
| slash bass (not a chord tone) | — | grey, ringed |

## Module rules

`build.mjs` bundles by rewriting imports, so modules may only use named exports on
declarations (`export function f`, `export const X`) and named relative imports
(`import { a } from './x.js'`). The build fails loudly on anything else.

`theory/`, `fretboard/`, `tunings.js` and `state.js` are pure — no DOM — and are what the
tests cover. `ui/` renders; `main.js` is the only place that touches `location`, `history`
and `localStorage`.
````
